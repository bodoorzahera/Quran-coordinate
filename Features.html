لماذا تستخدمه؟Why Use It?

  • دقة موثوقة: خوارزمية محاذاة تجمع بين مقاييس الخطوط وكشف الفراغات في الصور.Trusted accuracy: an alignment algorithm combining font metrics and image gap detection.
  • بيانات مفتوحة: كل الإحداثيات وقواعد البيانات مرفقة — لا قيود ولا خوادم خفية.Open data: all coordinates and databases bundled — no lock-in, no hidden servers.
  • متعدد المنصات: Python وJavaScript وويب (PWA) وأندرويد.Cross-platform: Python, JavaScript, web (PWA), and Android.
  • يعمل دون اتصال: الواجهة قابلة للتثبيت وتعمل بلا إنترنت.Offline-first: installable UI that works without internet.
  • سهل النشر مجانًا: استنسخ وشغّل، وانشر على استضافة مجانية بدون بطاقة — انظر دليل النشر.Free to deploy: clone, run, host free without a card — see the deploy guide.
  • مفتوح المصدر (MIT): استخدمه وعدّله وساهم فيه بحرية.Open source (MIT): use, modify, and contribute freely.
